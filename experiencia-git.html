Minha experiência com Git e GitHub

Nesta atividade, utilizei o Git para controlar as versões dos arquivos do meu portfólio e o GitHub para armazenar o repositório remoto.

Dificuldades encontradas

Uma das dificuldades encontradas foi a instalação e configuração inicial do Git no computador. Também tive dúvidas sobre o uso dos comandos pelo terminal e sobre o processo de clonagem do repositório.

Como resolvi

Resolvi essas dificuldades seguindo o passo a passo da atividade, instalando o Git corretamente e praticando comandos como git clone, git status, git add, git commit e git push, claro que não foi tudo perfeito, e quando eu acabava travado completamente em algo, eu pedia a ajuda a IA.

Conclusão

Durante a atividade, entendi que o Git é uma ferramenta utilizada para controlar versões dos arquivos e registrar alterações realizadas em um projeto. Também entendi que o GitHub funciona como um repositório remoto, permitindo armazenar e compartilhar projetos online.
