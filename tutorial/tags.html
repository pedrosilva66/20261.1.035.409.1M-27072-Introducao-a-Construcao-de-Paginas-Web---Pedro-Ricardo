Tags Audio e Video do HTML

Tutorial | Tags Audio e Video

Tag Audio

A tag audio permite reproduzir arquivos de som diretamente em uma página web.

Exemplo

Atributos da Tag Audio

  • src - Define o arquivo de áudio.
  • controls - Exibe os controles de reprodução.
  • autoplay - Inicia a reprodução automaticamente.
  • loop - Repete o áudio continuamente.
  • muted - Inicia o áudio sem som.
  • preload - Define como o áudio será carregado.

Tag Video

A tag video permite reproduzir vídeos diretamente no navegador.

Exemplo

Atributos da Tag Video

  • src - Define o arquivo de vídeo.
  • controls - Exibe os controles de reprodução.
  • autoplay - Inicia o vídeo automaticamente.
  • loop - Repete o vídeo continuamente.
  • muted - Inicia o vídeo sem som.
  • preload - Define como o vídeo será carregado.
  • poster - Define uma imagem de capa.
  • width - Define a largura do vídeo.
  • height - Define a altura do vídeo.
